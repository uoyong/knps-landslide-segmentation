# 18차 실험 기록

출발점은 17차 리더보드 0.7226459이며 목표는 0.75 이상이다. 리더보드 점수는 로컬 교차검증과 구분한다.

## 비교한 변경

1. 기존 1,468차원 존재 특징에 CatBoost 깊이 4/5 모델과 지역 균형 가중치를 적용했다. 기존 4모델 앙상블보다 일관된 개선이 없어 최종 존재 모델은 17차 것을 유지한다.
2. 픽셀 학습에서 희소한 양성 픽셀을 충분히 뽑되 중요도 가중치로 원래 면적 비중을 복원했다. 배경 기준 정규화 등을 더한 78차원 HGB 모델을 학습했다.
3. SAM 박스를 넓히고 점 프롬프트를 제거하는 후보를 345개 영상에서 검사했다. 경계 일부는 좋아졌지만 존재 판정과 합친 개선이 작았다.
4. 영상 유사도 및 인접 시점 기반 경계 평균은 개선이 제한적이었다.
5. SAM 인코더의 32채널 고해상도 특징과 배경 정규화 특징을 추가한 142차원 CatBoost 픽셀 모델을 학습했다. 기존 픽셀 모델과 절반씩 섞을 때, 가시 정답을 미리 안다고 가정한 래스터 경계 IoU는 창 분리 약 0.6103, 지역 분리 약 0.5842였다. 이 값은 공식 종합 점수가 아니다.
6. 존재 판정에 대칭 2상태 forward/backward 계산을 적용해 인접 시점의 정보를 반영했다. 작은 시퀀스의 모든 상태를 열거한 정확한 주변확률과 일치함을 확인했다.

## 검증

- 학습 영상 345개, 창 15개, 전체 추론 시점·개소 1,691건 중 평가 가능한 정답 1,601건을 사용한다.
- 존재 판정 학습과 점수 계산에서 ignore 정답을 제외한다. 해당 영상은 실제 제출과 마찬가지로 시계열 입력에 남긴다.
- 창 또는 상위 지역을 통째로 제외하는 5-fold 교차검증을 사용한다. 픽셀 정답이 전혀 없는 지역 31은 어떤 픽셀 학습에도 포함되지 않는다.
- SAM 가중치는 17차와 공통이다. 새 존재·픽셀 모델의 그룹 분리 결과이며, SAM 전체를 각 fold에서 다시 학습한 결과는 아니다.
- 512 해상도 확률을 1024로 확대해 임계값 적용 후, 제출과 같은 면적 필터와 폴리곤 변환을 적용한다. 경계 평가는 가시 정답 중 원본 면적 10픽셀² 이상에 한한다.
- 최종 선택은 창 분리 40%, 지역 분리 60%로 한다. 여러 후보 선택에 사용한 검증이므로 별도의 미사용 테스트 점수를 뜻하지 않는다.

## 주요 실행 파일

`full_oof.py`는 실제 입력 전체의 OOF 존재 확률을 만든다. `train_semantic.py --group scene/window`는 SAM 특징 픽셀 모델을 학습한다. `evaluate_semantic.py --group scene/window`는 최종 형태를 평가하고, `final_select.py`는 공식 비율(존재 macro-F1 60% + 개소별 형상 mIoU 40%)로 후보를 선택한다.

`build_submission.py`, `run_smoke.py`, `submit18.py`는 각각 제출물 구성, 실제 노트북 실행 검사, 서버 제출을 담당한다. 최종 결과는 `final_selection_report.json`과 `../18_submission/validation.json`에 저장한다.
